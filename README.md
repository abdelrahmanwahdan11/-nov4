# Mawaid Reset

This repository has been reset to a clean baseline so the Mawaid (سُفَر تراثية) redesign can be implemented without external package dependencies. The previous Greenly-oriented Flutter application was removed to comply with the new pure-Flutter, network-images-only requirements.

## Next steps
- Recreate the Flutter app structure under the new naming and domain concepts (banquets, dishes, occasions).
- Rebuild localization, routing, and state management using only Flutter SDK primitives.
- Introduce the NetImage widget and other custom UI elements following the updated specification.
